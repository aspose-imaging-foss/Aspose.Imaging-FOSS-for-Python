# Aspose.Imaging FOSS for Python

Порт библиотеки Aspose.Imaging.Foss на Python 3.10+. Для работы достаточно стандартной библиотеки Python. Исходная версия C# для сравнения — коммит `0f8899ff8372f6fd5b0d374a1c6b532b7c4cf92f`.

## Что уже работает

`detect_format()` распознаёт PNG (включая APNG), JPEG, GIF, BMP, WebP, ICO, TIFF, PSD, EMF, WMF, DICOM, DjVu, AVIF и HEIC. `probe()` также читает размеры EMF в пикселях по включительным границам прямоугольника и возвращает один кадр. На первом этапе у остальных форматов поля метаданных равны `None`. Для неизвестной сигнатуры обе функции возвращают формат `ImageFormat.UNKNOWN` напрямую или в поле `ImageInfo.format`.

Обе функции принимают путь, байтовый буфер или двоичный поток. Для распознавания достаточно первых 132 байтов. Чтение потока с перемоткой начинается с начала, а потока без перемотки — с текущей позиции. Поток вызывающей стороны остаётся открытым.

```python
from aspose_imaging_foss import ImageFormat, detect_format, probe

assert detect_format(b"GIF89a") == ImageFormat.GIF

info = probe("drawing.emf")
print(info.width, info.height, info.frame_count)
```

## Установка и проверка

Из корня проекта в виртуальном окружении выполните:

```sh
python -m pip install .
python -m unittest discover -s tests -v
```

## Этапы портирования

1. **Готово.** Упаковать библиотеку, перенести модель результата, распознавание 14 форматов и обработчик EMF. Проверить пути, буферы, короткие чтения и потоки без перемотки.
2. **Растровые изображения и WMF.** Перенести метаданные PNG/APNG, JPEG, BMP, PSD и WMF. Проверить варианты заголовков и число кадров APNG.
3. **Анимация и многостраничные изображения.** Перенести GIF, WebP, ICO, TIFF и DjVu. Сверить размеры и счётчики кадров или страниц с C#.
4. **Контейнерные форматы.** Перенести чтение метаданных DICOM, AVIF и HEIC. Проверить варианты порядка байтов DICOM и выбор основного изображения в AVIF/HEIC.
5. **Асинхронное чтение и итоговая сверка.** Перенести асинхронный API и отмену операций. Сравнить все поля обеих версий на общем наборе обычных, усечённых и повреждённых входных данных. Проверить установку собранного пакета.
